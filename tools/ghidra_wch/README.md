# Local Ghidra QingKe language

Generated by `tools/prepare_ghidra.py` from the installed Ghidra RISC-V SLEIGH sources. Upstream copyright
and license headers are retained in copied files. Original Ghidra files are never modified.

The generated `wch.sinc` implements the eight Xwchc encodings defined by
[LLVM PR 97925](https://github.com/llvm/llvm-project/pull/97925). `wch.slaspec` uses RV32 with 32-bit FPRs.
The selected compiler spec uses integer-register soft-float argument passing and injects actual GCC save-helper
stack effects for this firmware. An optional hardware-float spec limits floating parameters to four bytes.
`ghidra.external.modules` makes this module available to headless analysis.

`tools/validate.py` independently assembles boundary and one-hot offset vectors with LLVM, then verifies decoded operands
and pcode load/store widths using `DmtDecoderTest.java`. This is a firmware-specific analysis configuration;
other QingKe models or ABI variants require separate verification.
